# 发票解析系统 (Python 版本)

基于 pdfplumber 的发票 PDF 解析系统，从 PDF 格式的发票文件中提取结构化数据，并将结果导出到 Excel 文件。

## 项目结构

```
invoice/
├── src/
│   └── invoice/
│       ├── __init__.py
│       ├── main.py                    # 程序入口
│       ├── invoice.py                 # 数据模型
│       ├── invoice_service.py         # 发票解析主服务
│       ├── file_service.py           # 文件操作（查找、移动）
│       ├── excel_service.py          # Excel 导出服务
│       ├── text_utils.py             # 文本处理工具
│       ├── regex_utils.py            # 正则表达式工具
│       └── number_utils.py           # 数字处理工具
├── requirements.txt                   # 依赖包
└── README.md
```

## 安装依赖

```bash
pip install -r requirements.txt
```

主要依赖：
- `pdfplumber`: PDF 文本和表格提取
- `openpyxl`: Excel 文件操作

## 使用方法

### 基本使用

```bash
cd src/invoice
python main.py
```

### 修改配置

在 `main.py` 中修改 `base_path` 变量，指定发票文件所在目录：

```python
base_path = '/Volumes/share/temp/receipt'  # 修改为你的发票目录
```

## 处理流程

```
扫描PDF文件 → 解析发票信息 → 按日期组织文件 → 批量导出到Excel
```

### 详细流程

1. **扫描PDF文件**
- 在指定目录下查找所有 `.pdf` 文件

2. **解析发票信息**
- 使用 `pdfplumber` 提取文本和表格
- 过滤印章文字（红色）
- 提取基本信息：发票号码、开票日期、购买方、税号、发票类型
- 解析商品明细：项目名称、规格、单位、数量、单价、金额、税率、税额

3. **按日期组织文件**
- 将解析成功的发票文件移动到 `YYYY/MM` 目录结构下

4. **批量导出到Excel**
- 将所有发票数据写入 `invoice.xlsx` 文件
- 支持追加模式（如果文件已存在）

## 输出文件

- **Excel 文件**: `{base_path}/invoice.xlsx`
- 包含所有发票的明细数据
- 表头：发票号码、开票日期、购买方、项目名称、规格、单位、数量、单价、金额、税率、税额、发票文件名、录入时间、购买方统一社会信用代码/纳税人识别号、发票类型

- **日志文件**: `{base_path}/logs/app_{日期}.log`
- 记录处理过程和错误信息

## 核心功能

### 1. PDF 文本提取
- 使用 `pdfplumber` 提取文本和表格
- 自动过滤红色印章文字
- 支持文本流重组，解决乱序问题

### 2. 字段识别
- **发票号码**: 12-20 位数字
- **开票日期**: YYYY年MM月DD日 格式
- **购买方名称**: 支持公司名称、房间号等多种格式
- **购买方税号**: 18位统一社会信用代码验证
- **发票类型**: 普通发票/增值税专用发票

### 3. 商品明细解析
- 自动识别表头行
- 解析表格中的明细数据
- 支持跨行数据合并

### 4. 文件管理
- 按日期自动组织文件目录
- 支持文件移动和重命名

## 注意事项

1. **PDF 格式要求**:
- 仅处理第一页
- 需要包含可提取的文本（非纯图片）
- 建议使用标准格式的电子发票

2. **发票格式要求**:
- 需要包含标准的表头关键词
- 项目名称需要符合 `*项目名称*费用名称` 模式
- 日期格式需要是 `YYYY年MM月DD日`

3. **文件系统**:
- 文件移动支持跨文件系统（使用 `shutil.move`）

## 错误处理

- 解析失败的发票会记录错误日志，但不会中断整个流程
- 文件移动失败会跳过该文件，继续处理下一张
- Excel 写入失败会记录错误并退出
